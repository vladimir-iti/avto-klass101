# Проект: новый сайт автошколы «Авто-Класс»

Домен: `avtoklass-perm.ru`. Название: «Авто-Класс» (сохраняется).
Хостинг — reg.ru, отдельный аккаунт под проект (подключение и выкладка описаны ниже).

**Текущий этап:** сайт работает на боевом домене — 7 страниц (5 маркетинговых + документы
+ политика конфиденциальности), дизайн-система, новые тексты, адаптив, формы, приём заявок
в Google-таблицу и дата ближайшего набора группы.

## Главный документ

[`PROJECT-CONTENT.md`](PROJECT-CONTENT.md) — вся фактическая информация: организация, лицензии,
филиалы, площадка, кадры, автопарк, программы и часы, условия приёма, цены и рассрочка, экзамены,

## Правила работы

- Вся работа ведётся только внутри `~/Projects/avto-klass/`.
- Оригиналы материалов заказчика (zip-архивы) не изменяются.
- Материалы заказчика и материалы старого сайта хранятся раздельно — происхождение всегда видно.
- Старый сайт `avto-klass101.ru` используется только как источник фактов и медиафайлов;
  его тексты, структура и дизайн на новый сайт не переносятся.
- Утверждённые посадочные: `/`, `/category-b/`, `/category-a/`,
  `/professional/` (якоря `#c`, `#d`, `#be`, `#ce`, `#de`), `/tractor/`.
- Юридические и обязательные страницы образовательной организации — отдельно,
  в пять маркетинговых страниц не входят.

На рабочем столе есть символическая ссылка **«Авто-Класс»** на эту папку.

## Сайт (`site/`)

Статический сайт: HTML/CSS/vanilla JS, без фреймворков и CMS. Node используется только
как локальный сборщик шаблонов (`build.js`) — результат сборки в `site/dist/` полностью
статический и не зависит от Node на хостинге.

```bash
cd site
node build.js          # собрать dist/ из pages/ + partials/ + src/
node scripts/check.js  # проверка ссылок, якорей, meta, запрещённых данных
node scripts/serve.js  # локальный просмотр на http://localhost:4173/
```

Подробности архитектуры, тексты, тестирование — в отчёте, переданном вместе с этой версией.

## Хостинг и выкладка

Хостинг — **reg.ru**, обычный шаред без Node: на сервер уезжает только готовый `site/dist/`.

```
SSH-хост   regru-avtoklass-perm   (настроен в ~/.ssh/config)
сервер     server99.hosting.reg.ru, пользователь u3623826
корень     ~/www/avtoklass-perm.ru/
```

Выкладка — синхронизация собранного каталога:

```bash
cd site
node build.js && node scripts/check.js
rsync -az --delete dist/ regru-avtoklass-perm:www/avtoklass-perm.ru/
```

`--delete` убирает с сервера файлы, которых больше нет в сборке; перед реальным запуском
полезно прогнать то же самое с `--dry-run`.

Особенность хостинга: статика отдаётся с `Cache-Control: max-age=3888000` (45 дней) и без
своего `.htaccess`. Поэтому `build.js` дописывает к ссылкам на CSS и JS хэш содержимого
(`?v=…`) — иначе у постоянных посетителей неделями держались бы старые файлы.

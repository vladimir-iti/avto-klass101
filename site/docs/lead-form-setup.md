# Приём заявок с форм сайта в Google-таблицу

**Статус: код готов, эндпоинт не настроен.** Все формы на сайте
(`pages/index.html`, `category-a.html`, `category-b.html`,
`professional.html`, `tractor.html`) при отправке собирают четыре поля
(имя, телефон, категория, страница) и отправляют их через `fetch` на
URL веб-приложения Google Apps Script — тот же приём, что и в проекте
«Наш инкубатор» (`docs/booking-leads.md` там же).

Пока в `src/js/main.js` → `js/forms.js` вместо реального адреса стоит
плейсхолдер `LEAD_ENDPOINT_URL = 'REPLACE_WITH_APPS_SCRIPT_EXEC_URL'` —
форма валидирует поля и показывает «Заявка отправлена», но данные
никуда не уходят (в консоли браузера будет предупреждение об этом).

Ниже — как настроить приём один раз.

## Шаг 1. Создать таблицу

1. Откройте [sheets.google.com](https://sheets.google.com) → «Новая таблица».
2. Назовите её, например, «Заявки — Авто-Класс».
3. В первой строке (шапка) впишите заголовки колонок, ровно в этом
   порядке:

   ```
   Дата заявки | Имя | Телефон | Категория | Страница
   ```

## Шаг 2. Добавить скрипт

1. В таблице: **Расширения → Apps Script**.
2. Удалите весь код-заглушку в редакторе и вставьте этот:

   ```javascript
   function doPost(e) {
     var data = JSON.parse(e.postData.contents);

     var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

     sheet.appendRow([
       Utilities.formatDate(new Date(), Session.getScriptTimeZone(), "dd.MM.yyyy HH:mm"),
       data.name || "",
       "",
       data.category || "",
       data.page || ""
     ]);

     // Телефон пишем отдельно от appendRow и принудительно форматируем
     // ячейку как текст ("@") — иначе Google Таблицы видят "+7..." как
     // начало формулы и показывают #ERROR!.
     var lastRow = sheet.getLastRow();
     sheet.getRange(lastRow, 3)
       .setNumberFormat("@")
       .setValue(data.phone || "");

     var body =
       "Имя: " + (data.name || "") + "\n" +
       "Телефон: " + (data.phone || "") + "\n" +
       "Категория: " + (data.category || "") + "\n" +
       "Страница: " + (data.page || "");

     // try/catch — чтобы сбой отправки письма не мешал строке уже
     // попасть в таблицу, и чтобы ошибку было видно в журнале
     // выполнения (Executions), а не терять её молча.
     try {
       MailApp.sendEmail({
         to: "vick.gali4enko@yandex.ru",
         subject: "Новая заявка с сайта — " + (data.name || "без имени"),
         body: body
       });
     } catch (err) {
       console.error("Не удалось отправить письмо: " + err);
     }

     return ContentService
       .createTextOutput(JSON.stringify({ status: "ok" }))
       .setMimeType(ContentService.MimeType.JSON);
   }

   // Временная функция для проверки — имитирует настоящую заявку,
   // включая попытку отправить письмо. Можно удалить после того, как
   // почта заработает.
   function testLead() {
     doPost({
       postData: {
         contents: JSON.stringify({
           name: "Тест",
           phone: "+79990000000",
           category: "Категория B",
           page: "/category-b/"
         })
       }
     });
   }
   ```

3. Сохраните проект (значок дискеты), название можно оставить любое.

## Шаг 3. Опубликовать как веб-приложение

1. Кнопка **Развернуть → Новое развёртывание**.
2. Тип — **Веб-приложение**.
3. «Выполнять как» — **Я (ваш аккаунт)**.
4. «У кого есть доступ» — **Все** (это обязательно, иначе браузер
   посетителя сайта не сможет отправить данные).
5. Нажмите **Развернуть**, разрешите доступ (Google покажет
   предупреждение «Google не проверял это приложение» — это нормально
   для собственного скрипта, нажмите «Дополнительные настройки» →
   «Перейти на страницу (небезопасно)» → «Разрешить»).
6. Скопируйте выданный **URL веб-приложения** (заканчивается на
   `/exec`).

## Шаг 4. Прислать ссылку

Пришлите этот URL — он будет вставлен в `src/js/forms.js` вместо
`LEAD_ENDPOINT_URL`, сайт пересоберётся и переедет на боевой домен.
После этого каждая отправленная заявка (с любой из пяти форм) будет
новой строкой в таблице.

## Email-уведомления

Каждая заявка дополнительно шлёт письмо на `vick.gali4enko@yandex.ru` через
`MailApp.sendEmail` — письма уходят с адреса того аккаунта, под которым
развёрнут скрипт («Выполнять как» на шаге 3). Лимит — 100 писем/сутки
на обычном Google-аккаунте (для этого объёма заявок с запасом хватит).
Чтобы поменять адрес или добавить второй через запятую, отредактируйте
`to: "vick.gali4enko@yandex.ru"` в коде и передеплойте (см. ниже).

**Если письма всё ещё не приходят** (права уже выданы, версия
задеплоена, папка «Спам» проверена) — нужно посмотреть журнал
выполнения именно тех запусков, которые пришли с реального сайта
(не ручные тестовые), там будет настоящая причина:

1. В редакторе Apps Script слева — значок часов/списка **«Выполнение»**
   (Executions).
2. Отправьте с сайта тестовую заявку.
3. Обновите список выполнений — появится новая строка с недавним
   временем, инициатор — «Пользователь» или «Аноним» (не «Вы» — это
   отличает реальный вызов от ручного запуска).
4. Откройте её. Если строка в таблице появилась, но письмо не ушло, в
   этом же выполнении будет виден текст ошибки из `console.error` —
   пришлите мне его, и я скажу, в чём дело.

Частые причины на этом этапе: опечатка в адресе получателя, у аккаунта,
под которым выполняется скрипт, отключена отправка почты политикой
организации (если это Google Workspace, а не обычный gmail.com), либо
превышена суточная квота писем.

## Если понадобится изменить скрипт

Если в форму добавятся новые поля, в `doPost` нужно добавить
соответствующие `data.имя_поля` в `appendRow([...])` — имя поля берётся
из атрибута `name` соответствующего `<input>`/`<select>` в разметке
формы (`pages/*.html`), а затем **Развернуть → Управление
развёртываниями → изменить (карандаш) → Новая версия → Развернуть** —
URL при этом остаётся прежним.

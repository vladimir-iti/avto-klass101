# Дата ближайшего набора группы на сайте

На сайте в первом экране показывается блок с датой ближайшего набора:

> БЛИЖАЙШИЕ НАБОРЫ ГРУПП
> 🚗 Автомобили **22 сентября**   🚜 Трактор **7 октября**

Направления независимы — у каждого своя ячейка:

| Где | Что показывает | Ячейка |
|-----|----------------|--------|
| Главная `/` | обе даты сразу: автомобили и трактор | `B1` и `B2` |
| Категория B `/category-b/` | автомобильные категории | `B1` |
| Проф. категории `/professional/` | автомобильные категории | `B1` |
| Трактористы `/tractor/` | тракторные направления | `B2` |
| Категория A `/category-a/` | мотоциклы | `B3` |

Одна ячейка может питать несколько страниц: правка `B1` меняет дату сразу
на главной, в Категории B и в Проф. категориях.

**Чтобы поменять дату на сайте, достаточно отредактировать ячейку в таблице.**
Ни сайт, ни скрипт при этом трогать не нужно — новая дата появится у посетителей
в течение нескольких минут (у тех, кто заходил раньше, — при следующем заходе).

Источник — отдельная таблица **«Автокласс даты набора»**, не связанная с таблицей
заявок с форм. Это сделано намеренно: правка дат никак не может задеть приём
заявок.

---

## Таблица

Уже создана и заполнена:

|   | A | B |
|---|---|---|
| **1** | Автомобильные категории | `22.09.2026` |
| **2** | Тракторные категории | `07.10.2026` |
| **3** | Мотоциклы | `14.10.2026` |

Колонка **A** — подпись для вас, скрипт её не читает. Значение берётся из
колонки **B** первого листа таблицы (как он называется — неважно, `Лист1`
подходит).

**Формат ячейки B.** Вводите дату как обычную дату — `22.09.2026`. Google
Таблицы её распознают, а скрипт сам превратит в «22 сентября» на сайте:
склонять месяц и что-то дописывать не нужно.

Это же даёт защиту от забытой даты: если в ячейке настоящая дата и она уже
прошла, сайт перестаёт показывать строку целиком — посетитель не увидит
«ближайший набор — 22 сентября», когда на дворе октябрь.

Если нужно написать то, что датой не является («по мере набора группы»,
«с 1 по 5 октября»), — просто впишите текст. Он выведется как есть, но проверка
на просроченность тогда не сработает: следить придётся вручную.

Чтобы временно убрать направление с сайта — **очистите ячейку**. Его строчка
исчезнет; если опустеют все ячейки страницы, блок пропадёт целиком, и первый
экран будет выглядеть так же, как до его появления.

## Настройка — один раз

### Шаг 1. Добавить скрипт в эту таблицу

1. Откройте таблицу **«Автокласс даты набора»**.
2. **Расширения → Apps Script**. Откроется пустой проект, привязанный именно
   к этой таблице.
3. Удалите код-заглушку в редакторе и вставьте этот:

   ```javascript
   /* ------------------------------------------------------------------
      Даты ближайших наборов для сайта avtoklass-perm.ru.
      Читаются из первого листа этой таблицы:
        B1 — автомобильные категории
        B2 — тракторные категории
        B3 — мотоциклы
      ------------------------------------------------------------------ */

   var INTAKE_MONTHS = [
     'января', 'февраля', 'марта', 'апреля', 'мая', 'июня',
     'июля', 'августа', 'сентября', 'октября', 'ноября', 'декабря'
   ];

   function doGet(e) {
     var payload = {
       auto: readIntakeCell('B1'),
       tractor: readIntakeCell('B2'),
       moto: readIntakeCell('B3')
     };
     var json = JSON.stringify(payload);

     // Сайт сначала запрашивает данные обычным способом, а если браузер
     // такой запрос заблокирует — повторяет его вторым, запасным (он и
     // передаёт параметр callback). Поэтому нужны оба варианта ответа.
     // Имя callback проверяем по шаблону: подставлять в ответ то, что
     // пришло из адресной строки, без проверки нельзя.
     var callback = e && e.parameter ? e.parameter.callback : null;
     if (callback && /^[A-Za-z_$][A-Za-z0-9_$]*$/.test(callback)) {
       return ContentService
         .createTextOutput(callback + '(' + json + ');')
         .setMimeType(ContentService.MimeType.JAVASCRIPT);
     }

     return ContentService
       .createTextOutput(json)
       .setMimeType(ContentService.MimeType.JSON);
   }

   function readIntakeCell(cell) {
     // Именно первый лист, а не лист по имени: так название листа
     // («Лист1» или любое другое) не может стать причиной поломки.
     var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
     if (!sheet) return null;

     var range = sheet.getRange(cell);
     var shown = String(range.getDisplayValue() || '').trim();
     if (!shown) return null;

     // Основной разбор — по тому, что реально видно в ячейке: «22.09.2026».
     // Так результат не зависит ни от часового пояса таблицы и скрипта,
     // ни от того, каким именно объектом Google отдал значение.
     var parts = shown.match(/^(\d{1,2})[.\/-](\d{1,2})[.\/-](\d{4})$/);
     if (parts) {
       var day = Number(parts[1]);
       var month = Number(parts[2]);
       var year = Number(parts[3]);
       if (month >= 1 && month <= 12 && day >= 1 && day <= 31) {
         return {
           text: day + ' ' + INTAKE_MONTHS[month - 1],
           iso: year + '-' + pad2(month) + '-' + pad2(day)
         };
       }
     }

     // Запасной разбор: в ячейке дата, но показана в другом формате
     // (например «22 сент. 2026»). Проверяем по наличию getTime, а не
     // через instanceof Date — для значений из таблицы instanceof
     // срабатывает не всегда, из-за этого дата уезжала на сайт сырой.
     var value = range.getValue();
     if (value && typeof value.getTime === 'function' && !isNaN(value.getTime())) {
       return {
         text: value.getDate() + ' ' + INTAKE_MONTHS[value.getMonth()],
         iso: value.getFullYear() + '-' + pad2(value.getMonth() + 1) + '-' + pad2(value.getDate())
       };
     }

     // Произвольный текст («по мере набора группы») — отдаём как есть.
     return { text: shown, iso: '' };
   }

   function pad2(n) {
     return (n < 10 ? '0' : '') + n;
   }
   ```

4. Сохраните проект (значок дискеты). Название проекта — любое.

### Шаг 2. Опубликовать как веб-приложение

1. Кнопка **Развернуть → Новое развёртывание**.
2. Тип — **Веб-приложение** (шестерёнка рядом с «Выберите тип»).
3. «Выполнять как» — **Я (ваш аккаунт)**.
4. «У кого есть доступ» — **Все**. Это обязательно: иначе браузер посетителя
   сайта не сможет прочитать даты.
5. **Развернуть**. Google попросит разрешение — «Дополнительные настройки» →
   «Перейти на страницу (небезопасно)» → «Разрешить». Для собственного скрипта
   это нормально.
6. Скопируйте **URL веб-приложения** — он заканчивается на `/exec`.

### Шаг 3. Прислать ссылку

Пришлите этот URL — он будет вставлен в `site/src/js/intake.js`, сайт
пересобран, и даты появятся в первом экране. **Это единственный шаг, который
требует разработчика, и он делается один раз.**

Дальше смена даты — только правка ячейки.

### Шаг 4. Проверить

Откройте скопированный адрес `/exec` в браузере. Должна показаться строка вида:

```json
{"auto":{"text":"22 сентября","iso":"2026-09-22"},"tractor":{"text":"7 октября","iso":"2026-10-07"},"moto":{"text":"14 октября","iso":"2026-10-14"}}
```

Если вместо неё:

- **«Не удалось найти функцию скрипта: doGet»** — код сохранён, но развёрнута
  старая версия. Повторите шаг 2 (или **Развернуть → Управление развёртываниями
  → карандаш → Новая версия**).
- **Страница входа в Google** — на шаге 2.4 выбран доступ не «Все».
- **`{"auto":null,"tractor":null,"moto":null}`** — даты стоят не в колонке `B`
  или не в тех строках.

## Как это ведёт себя на сайте

Строка намеренно устроена так, чтобы **никогда не показывать неверную дату**.
Она не появится вовсе, если:

- ячейка пуста;
- скрипт не развёрнут или развёрнут без доступа «Все»;
- в ячейке настоящая дата, и она уже прошла;
- Google в этот момент недоступен, или у посетителя нет связи.

Во всех этих случаях первый экран просто выглядит так же, как раньше, — без
пустого места, «ошибки загрузки» и прочерков.

Полученная дата сохраняется в браузере посетителя на неделю: при повторном
заходе она появляется мгновенно, ещё до обращения к Google, и продолжает
показываться, даже если Google в этот момент недоступен. Свежая дата из таблицы
всё равно запрашивается при каждой загрузке страницы и заменяет сохранённую.

## Если понадобится изменить скрипт

После любой правки кода нужно **Развернуть → Управление развёртываниями →
карандаш → Новая версия → Развернуть**. URL при этом остаётся прежним, сайт
править не нужно.

## Если понадобится ещё одно направление

Например, отдельная дата для переподготовки. Нужно будет:

1. добавить строку в таблицу (следующая свободная — `B4`);
2. дописать `retraining: readIntakeCell('B4')` в `payload` внутри `doGet`
   и развернуть новую версию;
3. на стороне сайта — добавить направление в `GROUPS`
   (`site/partials/intakeBadge.js`: подпись, короткая подпись для узких
   экранов и иконка из `partials/icons.js`), завести токен в
   `site/build.js` рядом с `{{INTAKE_AUTO}}` и поставить его в нужный
   первый экран.

Первые два пункта делает заказчик, третий — разработчик.
